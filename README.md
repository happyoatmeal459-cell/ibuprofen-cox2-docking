# Ibuprofen–COX-2 Molecular Docking Analyzer

A Streamlit dashboard for a student project on:

**Evaluation of Ibuprofen–COX-2 Binding Interaction Using Molecular Docking**

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Open Streamlit Community Cloud.
4. Select the repository and `app.py`.
5. Deploy.

The app includes:
- project overview
- COX-2 and ibuprofen information
- docking workflow
- CSV upload for docking results
- score visualization
- interaction-table upload
- interaction charts
- simple report generator

## Important

The app intentionally uses clearly labeled example/demo docking values until your
actual docking results are uploaded. Do not present the demo values as experimental
results.
